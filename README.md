# Software Engineer Journey

A 12-week learning journey from QA Analyst toward software engineering, with TypeScript as my primary language.

## Learning approach

- Build programming ability by writing and explaining code myself.
- For new topics, start with explanations, hints, questions, and small exercises before showing a complete solution.
- For projects, review architecture and code, explain problems and tradeoffs, and leave decisions with me.
- Practice professional habits: Git, GitHub, testing, documentation, and CI/CD.

Example input: `[72, 55, 92, 75]`
