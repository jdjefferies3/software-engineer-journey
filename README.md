# Score Tracker

A small TypeScript program that summarizes quiz scores.

## Features

- Calculate the average score.
- Find the highest score.
- Count passing scores (60 or higher).
- Return a readable summary, including sensible handling for an empty score list.

## Example input

```ts
[72, 55, 92, 75]
```

This is a Week 1 practice project for learning TypeScript fundamentals.
